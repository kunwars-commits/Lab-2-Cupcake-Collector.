# Lab 2: Cupcake Collector

## Game Description
In **Cupcake Collector**, you control a cute red character navigating across floating platforms. Your goal is to collect all 10 delicious cupcakes scattered across the stage.
- **Left Arrow**: Move Left
- **Right Arrow**: Move Right
- **Up Arrow / Spacebar**: Jump
- **R Key**: Restart game after collecting all cupcakes
- 
## Objective
Collect all 10 cupcakes to win. A counter tracks how many cupcakes remain. Sound effects play when you jump, collect a cupcake, and complete the game.

## Running Locally
1. Install Python 3.10+ and Pygame:
   ```bash
   pip install pygame
   ```
2. Run the game:
   ```bash
   python main.py
   ```
